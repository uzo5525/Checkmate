# Checkmate 개인정보처리방침

> 공개본은 앱의 `/privacy` 화면(https://readygo.expo.app/privacy)입니다. 내용을 바꾸면 `src/app/privacy.tsx`도 함께 고치세요.

시행일: 2026년 11월 6일

팀 여행의 숲(이하 "팀")은 Checkmate 앱(이하 "앱")을 이용하는 분의 개인정보를 소중히 다루며, 필요한 최소한의 정보만 처리합니다.

## 1. 처리하는 정보와 목적

| 구분 | 항목 | 목적 | 저장 위치 |
|---|---|---|---|
| 계정 | 기기별 익명 식별자(회원가입·이메일 없음) | 내가 참여한 여행 구분, 접근 권한 확인 | 서버(Supabase) |
| 여행 방 | 닉네임, 여행지·국적·출발/귀국일·인원, 방 코드 | 여행 준비 공유 | 서버 |
| 준비 기록 | 체크리스트 완료 여부, 공유 항목 담당자, 직접 추가한 항목 | D-day 체크리스트, 동행 진행률 | 서버 |
| 여행 코스 | 제안한 장소 이름·메모·좌표, 투표, 날짜별 일정 | 장소 투표와 일정 공유 | 서버 |
| 서류 확인 | 여권 영문 성명·만료일, 보험 보장 시작·종료일 | 여행 일정과 대조 | **이 기기에만** |
| 짐 | 짐 리스트, 반입 규정 확인 목록 | 짐 준비 | **이 기기에만** |
| 보관함 등 | 직접 넣은 파일, 질문 답변, 숙소 주소, 오프라인용 여행 사본 | 서류 보관, 여행 중 확인 | **이 기기에만** |

### 처리하지 않는 정보
- **여권번호, 생년월일**: 여권 하단(MRZ)에서 검증에만 쓰고 보관하지 않습니다.
- **서류 사진**: 기기 안에서 글자만 읽고 전송하지 않습니다. 사용자가 직접 보관함에 넣은 파일만 기기에 남습니다.
- 위치 정보(GPS), 연락처, 결제 정보는 수집하지 않습니다.

### 동행자에게 보이는 정보
- 닉네임, 개인 체크리스트의 **진행률(몇 개 중 몇 개 완료)**, 공유 항목과 담당자, 제안한 장소와 투표
- 방장에게는 여권·보험·비자·입국 서류 항목의 **체크 여부**도 보입니다. 서류 내용은 보이지 않습니다.
- 개인 체크리스트의 세부 항목, 서류 정보, 짐 리스트는 보이지 않습니다.

## 2. 외부 서비스 이용

| 서비스 | 제공 업체 | 내용 |
|---|---|---|
| 데이터 저장·동기화 | Supabase Inc. (서버 위치: 일본 도쿄 리전) | 위 "서버" 항목 저장 |
| AI 준비 에이전트·일정 정리 | Anthropic, PBC (Claude API) | 여행 상태 요약(남은 날짜, 체크리스트 항목 제목과 완료 여부, 동행 진행률 수치, 장소 이름)을 보내 브리핑·일정을 만듭니다. 서류 정보와 사진은 보내지 않습니다. 지도 링크를 넣으면 위치를 찾기 위해 링크의 장소 이름과 주소도 보냅니다. |
| 장소 위치 찾기 | OpenStreetMap Nominatim | 지도 링크의 영어 장소 이름과 주소를 보내 대략적인 위치를 찾습니다. 기기의 인터넷 주소(IP)가 전달됩니다. |
| 지도 | Google Maps SDK(앱), OpenFreeMap(웹) | 지도 표시. Google 개인정보처리방침이 적용됩니다. |
| 문자 인식 | Google ML Kit(앱), Tesseract(웹), 기기 내 처리 | 서류·라벨 글자를 기기 안에서 읽습니다. 사진은 전송되지 않습니다. |
| 날씨·환율·재난 정보 | Open-Meteo, ExchangeRate-API, P2P지진정보, GDACS, USGS | 여행지 정보만으로 조회합니다. 요청 시 IP가 전달될 수 있습니다. |

## 3. 보관 기간과 삭제
- 여행 데이터는 방장이 여행을 삭제하거나, 멤버가 여행에서 나가면 해당 정보가 삭제됩니다.
- AI 결과(브리핑·일정 문구)는 여행이 삭제될 때 함께 삭제됩니다.
- 기기에만 저장된 정보는 앱 안의 "입력한 정보 지우기" 또는 앱 삭제로 지워집니다.
- 앱을 삭제하면 익명 식별자가 사라져 이전 여행에 다시 접근할 수 없습니다(방 코드로 다시 참여 가능).

## 4. 이용자의 권리
언제든지 자신의 정보 열람·수정·삭제를 요청할 수 있습니다. 앱에서 직접 삭제하거나 아래 연락처로 요청해 주세요.

## 5. 아동
만 14세 미만 아동을 대상으로 하지 않으며, 아동의 정보를 알고 수집하지 않습니다.

## 6. 안전성 확보 조치
- 서버 데이터는 행 단위 보안 규칙(RLS)으로 해당 여행 멤버만 접근할 수 있습니다.
- AI·지도 등 외부 API 키는 앱에 넣지 않거나 앱 전용으로 제한합니다.

## 7. 문의
- 운영: 여행의 숲
- 연락처: Google Play 앱 정보에 있는 개발자 연락처 (`APP_CONFIG.contactEmail`을 채우면 앱에 표시)

본 방침이 바뀌면 앱 또는 이 페이지에서 알려 드립니다.
